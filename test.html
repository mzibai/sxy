Laravel 函数与参数练习题

依据当前《函数参考》编写，考查 PHP 内置函数、Laravel 辅助函数、门面及框架方法。共 16 题，满分 56 分，建议用时 60–90 分钟。

一、参数基础（第 1–8 题，共 24 分）

第 1 题：md5 的作用与使用场景（3 分）

1. md5 的作用是什么？（1.5 分）
2. 请举一个 md5 的使用场景，并说明用途。（1.5 分）

第 2 题：日期格式与默认时间戳（3 分）

$a = date('Y-m-d', 0);
$b = date('H:i:s', 0);
$c = date('Y-m-d');

写出 $a、$b 的值；解释 date 函数第 1、2 个参数的作用；说明 $c 使用哪个时间戳。

第 3 题：拆分数量限制（3 分）

$a = explode('|', 'ADMIN|WORKER|USER');
$b = explode('|', 'ADMIN|WORKER|USER', 2);
$c = explode('|', 'ADMIN|WORKER|USER', -1);

逐个写出结果数组，并解释 explode 函数第 3 个参数的作用。

第 4 题：是否严格比较（3 分）

$a = in_array('1', [1, 2]);
$b = in_array('1', [1, 2], true);
$c = in_array('WORKER', ['ADMIN', 'WORKER'], true);

判断每次调用返回 true 还是 false，并说明原因；解释 in_array 函数第 1、2、3 个参数的作用。

第 5 题：响应体状态与 HTTP 状态（3 分）

$a = response()->json(['code' => 404, 'message' => 'not found']);
$b = response()->json(
    ['code' => 404, 'message' => 'not found'],
    404,
    ['X-Scene' => 'practice']
);

分别给出 HTTP 状态码，说明响应体 code 是否能自动改变 HTTP 状态；再解释本题使用的 json 前三个参数及 response() 无实参调用的返回对象。

第 6 题：请求数据来自哪里（3 分）

$a = $request->query('token');
$b = $request->post('token', 'missing');
$c = $request->all(['username', 'avatar']);
$d = $request->query();

给出 $a、$b、$d；说明 $c 包含哪些键和值的类别。解释 Request 的 post、query 方法第 1、2 个参数，以及 all 方法第 1 个参数的作用。

第 7 题：验证器的消息与字段名（3 分）

$validator = Validator::make(
    ['number_guest' => 0],
    ['number_guest' => 'required|integer|min:1'],
    ['number_guest.min' => ':attribute至少为:min'],
    ['number_guest' => '就餐人数']
);
$failed = $validator->fails();

逐一解释 Validator::make 方法第 1 至第 4 个参数的作用；判断 fails() 的返回值，并说明 messages 与 attributes 的分工。Validator::make 方法的第 3、4 个参数省略时分别使用什么默认值？

第 8 题：允许值验证规则（3 分）

$rules = [
    'table_type' => ['required', __________],
];

补全下方规则，让 table_type 只能为 A、B、C，并保持必填。说明 Rule::in 方法第 1 个参数的作用，判断传入 D 和 A 时该允许值规则分别是否通过。

二、代码阅读与纠错（第 9–16 题，共 32 分）

第 9 题：条件参数与查询结果（4 分）

$rows = Booking::query()
    ->where('status', '!=', 'CONFIRM')
    ->where('contact_name', 'like', '%林%')
    ->get(['id', 'contact_name']);

写出结果中的 id；解释两个 where 的前三个参数。再解释 where('status', 'VALID') 与 firstWhere('status', 'VALID') 的区别，以及未显式传入 where 方法的第 4 个参数时，多个条件使用什么方式连接。

第 10 题：构造器、模型与集合（4 分）

$a = User::query();
$b = User::query()->find(1, ['id', 'username']);
$c = User::query()->find(999);
$d = User::query()->where('id', 999)->get();
$e = User::query()->where('id', 999)->first();
$f = User::all(['id', 'username']);

说明下列变量的对象/值类别；对于空结果写清是 null 还是空集合。另外，find 方法第 2 个参数，以及 get、first、all 方法第 1 个参数的作用和默认值是什么？query 是否声明参数？

第 11 题：单个模型不能当集合映射（4 分）

$meal = Mealing::query()->find($mealId)->load('table');
return response()->json($meal->map(function ($item) {
    return [
        'id' => $item['id'],
        'table_id' => $item['table']['id'],
    ];
}));

下面代码有两个运行时问题。找出问题，并改成“找不到记录返回 HTTP 404，找到时返回单条用餐信息”的实现。不要使用集合包裹单个模型。最后说明这里的 load 方法由什么对象调用，以及 map 方法应由什么对象调用、其第 1 个参数中的回调通常收到哪些参数。本题保证找到的用餐记录一定有关联桌位。

第 12 题：创建模型与直接插入（4 分）

$a = User::query()->create([
    'username' => 'a',
    'password' => 'demo',
    'type' => 'USER',
    'token' => '',
]);
$b = User::query()->insertGetId([
    'username' => 'b',
    'password' => 'demo',
    'type' => 'USER',
    'token' => '',
]);

比较返回值、fillable、模型事件、created_at/updated_at 的处理。解释 insertGetId 方法第 1、2 个参数的作用；timestamps() 为什么不能保证每次插入都自动填时间？

第 13 题：更新与删除的接收对象（4 分）

$user = User::query()->find(7);
$updated = $user->update(['token' => 'new-token']);
$deleted = $user->delete();

解释模型 update 方法第 1、2 个参数的默认值和作用；说明两个返回值的类型、数据库变化以及是否经过模型事件流程。delete 是否需要传入 ID？如果 find 没有结果，代码应在哪里补充判断？

第 14 题：字段参数中的错误注释（4 分）

$table->char('table_type');             // 默认长度就是 1
$table->double('amount', 8, 2);         // 后两个参数设定总位数和小数位
$table->integer('queue_number', true, true); // 普通、不自增、有符号整数
$table->time('dining_time', 3);
$table->timestamps(0);

使用文档中的 Laravel 版本，指出前三行注释的问题并修正代码，使目标分别为“固定长度 1 的桌型”“普通 double 金额”“不自增的有符号整数”。再解释 time 方法第 2 个参数、timestamps 方法第 1 个参数的作用。注意区分“传入未声明的额外参数”和“该 API 实际支持这些参数”。

第 15 题：最新是按哪个字段定义的（4 分）

$a = Mealing::query()->where('table_id', 3)->latest('id')->first();
$b = Mealing::query()->where('table_id', 3)->latest()->first(['id', 'table_id']);

$a、$b 各返回哪个 ID？解释 latest 方法第 1 个参数的默认值与函数内部回退值，以及 first 在这里的作用。

第 16 题：嵌套路由与中间件参数（4 分）

Route::prefix('v1')->middleware('auth2:ADMIN')->group(function () {
    Route::prefix('table')->group(function () {
        Route::get('/{id}', [TableController::class, 'getTable']);
        Route::post('/', [TableController::class, 'createTable']);
        Route::delete('/{id}', [TableController::class, 'deleteTable']);
    });
});

Route::redirect('/', '/register.html');

写出三条 API 的 HTTP 方法与完整路径；解释 Route 的 get、post、delete 方法第 1、2 个参数的作用，以及 middleware、group 方法各自第 1 个参数的作用；说明重定向入口、目标和默认 HTTP 状态。GET 是否同时支持 HEAD？
